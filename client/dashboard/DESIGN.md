# Dashboard Design Authority

The dashboard implements the root [DESIGN.md](../../DESIGN.md): **Live Match Director**, an evidence-first operations surface based on score ribbons, program monitors, calibrated signal plots, and production rundowns. All color, typography, geometry, responsive behavior, chart, and prohibited-pattern rules in the root document are binding for this app.

No UI file may contain literal color values. Runtime UI references semantic tokens defined in `app/globals.css` and mapped to Tailwind utilities.
